# NetTest Windows 发布说明 — 2026-11-16

## 安装

解压完整的 `NetTest-windows-x64-20261116.zip`，运行 `nettest.exe`。
不要只复制 EXE；同目录 DLL 和 `data` 文件夹必须一并保留。

## 顶部标题可复制与字体优化

- 顶部显示的 NetTest、进程名、PID 和当前页面标题现在可以鼠标拖选。
- Windows 上可右键复制，也可以使用 `Ctrl+C`；标题过长时可横向滚动查看。
- 标题优先使用 Cascadia Code，回退到 Cascadia Mono、Consolas 和 Microsoft YaHei UI，并使用较粗字重，提高进程名、PID 和中文页面名称的可读性。
