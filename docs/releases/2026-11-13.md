# NetTest Windows 多开版 — 2026-11-13

## 安装

解压完整的 NetTest-windows-x64-20261113.zip，运行 nettest.exe。
不要只复制 EXE；同目录 DLL 和 data 文件夹必须一并保留。旧版本 ZIP 不包含最新多开功能。

## 自定义进程名多开

1. 打开程序后，点击右上角「多开」。
2. 填写新进程名，例如 nettest_A 或 nettest_B.exe。
3. 选择是否复制当前设置和 URL 历史，点击「启动新实例」。
4. 在任务管理器「详细信息」中查看对应的 EXE 名称；「进程」页可能仍使用 NetTest 产品描述。

这会启动真实的不同文件名进程，不修改其他程序的进程信息。当前窗口不能原地更改自身进程名。
关闭主窗口不影响新实例。各实例的配置、URL 历史、内存日志和下载目录独立。

## 目录与注意事项

- 实例运行文件保存在应用数据目录 instances/<实例ID>/bundle/，配置在同级 profile/。
- 下载默认保存在 profile/downloads/，不会复用主程序的下载路径。
- 新实例默认关闭固定端口段；若要抓包，请自行分配不重叠的范围。
- 多开会复制运行文件，占用一定磁盘空间；不用的副本可在关闭对应进程后自行清理。
- 再次双击同一份已创建 EXE 会复用它自己的 profile；需完全隔离的新实例请从「多开」按钮另建。
- 已创建的副本不会自动升级；更新主程序后，需要新版的实例应重新创建。
- 保留 2026-11-11 的日志面板自动跟随修复和 2026-11-04 的网络稳定性修复。
- 此次只交付 Windows 新版，不改变 Android 安装包。
