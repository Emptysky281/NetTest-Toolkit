# NetTest 使用指南

Windows 与 Android 的差别：
- 设置与 URL 历史：Windows 存在 `%APPDATA%\com.nettest\nettest\`，Android 存在应用私有目录。
- 默认保存目录：Windows 为「文档\NetTest\downloads」，Android 为 `Android/data/com.nettest.nettest/files/downloads/`。
- 手动 TLS 分阶段：Windows 用随程序附带的 OpenSSL 3（`libssl-3.dll` / `libcrypto-3.dll`），校验证书时使用 Windows 系统证书库；Android 用系统 `SSLEngine`。
  证书校验失败时回给服务器的告警码不同：Windows(OpenSSL) 为 48 unknown_ca，Android 为 46 certificate_unknown，两者都正确。
- 回包超时=0（不限时）：Windows 设置 `TCP_MAXRT` 为不限，Android 设置 `TCP_USER_TIMEOUT` 为不限。
- 系统代理：Windows 读取「Internet 选项」中的系统代理（http 或 socks），Android 读取 Wi-Fi 全局 HTTP 代理。
- 导出 CSV / 保存日志：Windows 弹出「另存为」对话框（默认在保存目录、带时间戳的文件名，取消则不保存）；Android 直接存到保存目录。

## 功能
- **各页独立**：单连接、多连接、分阶段各自填写目标 URL（输入框可直接输入，也可点右侧箭头从 URL 历史选择），三页共用一份 URL 历史，在「设置」页可清空。单连接与多连接可以同时运行，各页的「停止」只停本页；分阶段本来就是独立的连接。分阶段 ① 建连后，②～⑥ 使用建连时的 URL，之后改输入框不影响当前连接。旧版本在「设置」页填的目标 URL 会在首次打开时自动填到三个页面。
- **分页日志**：单连接、多连接、分阶段页面下方的日志只显示本页发起的连接；「日志」页显示全部（按时间顺序）。各页单独保留最近 5000 条，多连接刷屏不会挤掉单连接/分阶段的记录。「日志」页的「清空」会清空所有页面。
- **多连接 keep-alive 实时状态**：勾选 keep-alive 时，请求完成的连接保持打开，列表每 0.5 秒刷新「持续 / 空闲」时长。状态纯被动读取（只看已收到的数据、FIN、RST），不发任何探测包。
  「保持(s)」> 0 到时关闭；为 0 则一直保持，直到点「停止」或服务器主动关闭（显示「对端断开」和存活时长，可用来测服务端 keep-alive 超时）。保持中的空闲连接不占并发上限。
- **超时**：设置页分两项。「连接超时」管 DNS / TCP 握手 / 代理 / TLS，填 0 表示本程序不限时，由系统 SYN 重传决定何时放弃；
  「回包超时」管连接建立后多久收不到数据才判定超时，填 0 表示一直等待、连接不断开，并把 TCP_USER_TIMEOUT 设为不限。
  等待期间只被动显示进度，不发探测包；重传是操作系统按 TCP 协议自动做的，应用无法关闭。
- **记住设置**：所有页面的选项保存在应用私有目录的 `settings.json`，下次打开自动恢复；每秒检查一次有变化就写入，切到后台时也会保存。清除应用数据即恢复默认。目标 URL 和分阶段载荷不再预填示例，首次打开为空，未填 URL 时运行会先提示。注意代理密码以明文保存。
- **不做 TLS 握手**：单连接、多连接都可勾选「仅 TCP 握手后直接发请求」，勾选后，https:// 的连接也不做 TLS 握手，TCP 握手完成后直接发送明文 HTTP 请求，端口和 Host 头不变（http:// 不受影响）。用于测试明文请求打到 TLS 端口、或被中间设备拦截时的表现；例如对 https://example.com/ 会收到服务器返回的 400。默认不勾选。
- **多连接每条 URL**：默认勾选「全部连接使用目标 URL」；取消勾选后点「编辑每条连接的 URL」，每条可直接输入或点右侧箭头从 URL 历史选择，留空的连接用目标 URL，可「用 #1 填充全部」或「全部清空」。连接列表与 CSV 显示每条连接实际用的 URL，用到的 URL 都会记入历史。
- **URL 历史记录**：每次运行自动记入历史（最多 20 条，重启后保留），各页输入框右侧下拉选择，可在设置页清空；清空后仍会正常保存新的历史记录。
- **自定义载荷**：单连接/多连接都可在请求头下方填「自定义载荷」，作为 HTTP 请求正文发送，自动补 `Content-Length`；支持 `\r \n \t \0 \\ \xNN` 转义，留空则与原来完全一致。
- **载荷历史**：单连接、多连接、分阶段的自定义载荷共用一份历史记录（最多 20 条，最新在前，重复的会移到最前），运行或发送时记入，下拉选取，可清空，重启后保留。分阶段页的载荷不再预填示例请求。
- **单连接 / 多连接**：keep-alive 多请求、请求间隔、保持连接、仅建 TCP、请求分段发送、附加请求头；多连接支持总数 / 并发上限 / 建连间隔，汇总成功率与 TCP / 代理 / TTFB 的 avg/p50/p95/max、吞吐，导出 CSV。
- **TCP/TLS 分阶段**：① TCP 握手 → ② 发 ClientHello（停住等回包）→ ③ 继续握手 → ④⑤⑥ 请求行 / 头 / 空行。TLS 由 Android `SSLEngine` 手动驱动，每条 TLS 记录都解析显示；ClientHello 可分片；自定义载荷；半关闭 / FIN / RST。
- **出站**：direct（可被 v2rayNG / Xray VPN 模式透明劫持）、SOCKS5、HTTP CONNECT、系统 Wi-Fi 代理。
- **证书**：默认**不校验证书**，自签名 / 过期 / 域名不匹配 / 不受信任的根都能连上，每张证书的 subject、issuer、有效期会记录到日志。
  设置页勾选「强制校验证书」后恢复严格校验（证书链 + 有效期 + 主机名），坏证书会握手失败。
  手动 TLS 页的「校验证书」默认也跟随该设置，可单独勾选/取消覆盖，点「恢复跟随全局」撤销覆盖。
- **下载**：边收边写盘，保存到 `Android/data/com.nettest.nettest/files/downloads/`，命名同 `curl -O`；断开存为 `*.incomplete`；空闲超时；每秒进度与速度。
- **抓包过滤**：固定本地端口段（默认 40000-40999）。

## 注意
- Cloudflare 等服务器在 TLS 握手后约 10 秒没收到请求会主动断开，分阶段测试时 ③ 之后要尽快发请求。
- 用 v2rayNG 的分应用代理时，不要把本应用放进“绕过”列表，否则不会被劫持。
- 用户态 socket 无法单独发 SYN，① 是完整三次握手。


## Windows 日志滚动

- 日志使用固定底部锚点，避免大响应、不同高度的日志行以及达到 5000 条后淘汰旧日志时向上跳动。
- 开启「自动滚动」时持续显示最新输出；主动上翻暂停跟随并保留阅读位置，回到底部或重新开启自动滚动后恢复。
- 横向查看长载荷不会影响纵向跟随，切换页面、调整窗口大小和 HEX/载荷显示也保持最新位置。
- 回归测试：`flutter test test/log_scroll_test.dart`（Windows 平台模式，覆盖逐帧跟随、鼠标滚轮/拖动、日志淘汰与页面切换）。


## Windows 自定义进程名多开

- 点击顶部「多开」，输入新实例进程名（如 `nettest_A`、`nettest_B.exe`）后点「启动新实例」。名称可带 `.exe`，不能包含路径、Windows 保留名称或非法文件名字符。
- 这不是只改窗口标题：会复制当前版本的运行文件，并以指定文件名的独立 EXE 启动。请在任务管理器「详细信息」页查看 EXE 名称；「进程」页可能仍显示产品描述 NetTest。
- 每次从按钮创建的新实例使用独立运行目录、设置、URL 历史、日志和下载目录；可选择复制当前设置与历史，不会复制或自动运行正在执行的网络测试。
- 新实例默认关闭固定本地端口段，避免复制同一端口范围产生绑定冲突；如需按端口抓包，请为不同实例单独设置不重叠的范围。
- 运行副本保留在应用数据目录 `instances/<实例ID>/bundle/`，设置在同级 `profile/`，下载在 `profile/downloads/`。每份运行副本需要一定磁盘空间；不是在原安装目录改名，因此只读安装目录也可使用。
- 创建的 EXE 与同目录 DLL/data 文件应一起保留；之后再次打开该 EXE 会使用它自己的 profile。主程序/其他实例关闭不影响已启动的新实例。
- 新窗口会显示 EXE 名称和 PID，保存对话框按当前窗口 PID 绑定。该功能仅支持 Windows；Android 不提供桌面进程名多开。
