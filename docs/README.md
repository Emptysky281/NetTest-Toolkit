## 文档维护规则

- 用户操作写入使用指南，工具命令写入开发指南，模块职责写入架构文档。
- 测试新增或移动时，同时维护测试说明和脚本中的发现规则。
- 历史发布说明描述当时的交付，不用后续源码状态覆盖历史记录。
- 构建日志、用户配置、下载内容和安装包不放进文档目录；缓存与历史产物留在原有的被忽略目录。
